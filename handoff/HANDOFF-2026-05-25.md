### Not Working / Needs Fix

#### 1. Oracle Field Identification
Fill Personal fills `fullName` and phone country code, but NOT `firstName`, `lastName`, `email`, `phoneNumber`. JC detects 8 personal fields but `fillField()` returns false for some. Suspect: `identify()` doesn't map Oracle's `name="firstName"` to `first_name` correctly, or `fillMap` has empty values for those keys. Needs debugging via extension's isolated world.

#### 2. Oracle Knockout Forms
Programmatic clicks on Next/Verify buttons throw "Uncaught" because Knockout observables aren't updated by DOM manipulation. Checkbox `legalDisclaimer.isAccepted` observable resists `el.checked = true` + `dispatchEvent(change)`. The `clickxy` (mouse coordinate) approach also fails. Workaround: user clicks these buttons manually.

#### 3. CDP Tool Daemon Crashing
The cdp tool (`cdp.mjs`) daemon crashes on Oracle SPA pages because `Runtime.enable` triggers a flood of `console.log` events from Oracle's JS. The daemon times out or "Connection closed before response". Workaround: direct Node CDP scripts with `Page.addScriptToEvaluateOnNewDocument` (console suppression) before navigation. OR use the bridge's WebSocket directly.

#### 4. Bridge Fragility
`scripts/launch_with_ext.mjs` crashes when:
- Multiple WebSocket clients connect/disconnect rapidly
- Pipe data isn't consumed fast enough (Oracle page flood)
- Unhandled pipe errors (mitigated with `process.on('uncaughtException')` hooks)

#### 5. Content Script Isolated World
`FormDetector` and `LLMClient` are in MV3's isolated world — NOT accessible from `Runtime.evaluate` (main world). Can only see DOM changes (filled field values, button presence). Need `chrome.scripting.executeScript` or world-specific eval to debug field identification.
