## Key Decisions Made This Session

### 1. CDP is last resort, not primary strategy
`chrome.debugger.attach()` conflicts with `--remote-debugging-pipe`. **The extension must never rely on CDP for form filling.** CDP (`scripts/cdp.mjs`) is for our development debugging only.

### 2. New fallback chain (per research)
```
1. Direct DOM value + events
2. Native value setter (Object.getOwnPropertyDescriptor prototype setter)
3. Character-by-character typing (progressive value.substring(0,i+1) + input events)
4. InputEvent per-character (new InputEvent('input', {inputType: 'insertText'}))
5. CDP insertText (LAST RESORT, unreliable on pipe mode)
```

Confirmed by real-world autofill extensions (Workday ext GitHub, FormFill Vault Dev.to article).

### 3. Remove `debugger` permission from manifest
The extension should work in any Chrome without special permissions. The `chrome.debugger` handler in background.js (`jc_cdp_fill_combobox`) should be stripped — the extension code should never call it.

### 4. Month value format fix needed
Oracle CX month comboboxes expect month names ("Mar", "April") or zero-padded numbers ("03"), not bare numbers ("3"). `parseDateParts()` in content.js needs to format months correctly.
