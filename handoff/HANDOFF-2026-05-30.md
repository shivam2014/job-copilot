## Key Learnings (for chrome-ext-test skill)
- Extension CSS sometimes doesn't inject via manifest → use `<style>` tag in content.js
- NEVER touch `#devMode` toggle on chrome://extensions — it toggles state on click
- Check `#errors-section` on chrome://extensions after every reload
- Oracle combobox: value stored in toggle button text, not input.value
- Oracle combobox options: `.cx-select__list-item` inside `.cx-select__list`
- `overflow: hidden` on ancestors clips F button → override on ALL ancestors up to body
- Paste approach (`insertFromPaste`) works for text fields, not for comboboxes (need dropdown click)
