### Key Learning: Extension Reload

Chrome extension reload via chrome://extensions DOES work and does NOT cache content scripts. BUT you must reload the target page afterward for the new content script to inject. Without `page.reload()`, the old content script keeps running. This caused hours of debugging — trace logs from new code didn't appear because old code was still executing.

Updated `~/.codex/skills/chrome-ext-test/SKILL.md` with this and other learnings.
