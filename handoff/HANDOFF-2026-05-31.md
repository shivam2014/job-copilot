## What Was Done

### CDC CLI Tool (~/tools/chrome-cdp/)
Built a complete Chrome DevTools CLI for extension development. GitHub repo: https://github.com/shivam2014/chrome-cdp-cli

**Commands built:**
- `cdc list/status` — Chrome health check
- `cdc reload-ext/refresh-page` — extension management
- `cdc layout actionable/tree` — page layout extraction via accessibility tree
- `cdc fill/clear/click/check/verify/type` — field interaction with structured results (`{ ok, actual, strategy, error, message, duration }`)
- `cdc fill-many` — bulk fill (one connection, 4x faster)
- `cdc options` — list dropdown/combobox options
- `cdc hover` — hover events
- `cdc dev-mode` — toggle/query Chrome developer mode
- `cdc ext-errors` — read/clear extension errors from chrome://extensions

**Key design decisions:**
- `cdc fill` verifies value 500ms after setting (catches Oracle/Knockout async clearing)
- `cdc ext-errors` auto-enables dev mode before checking errors
- `--wait` flag for async element resolution
- `duration` field in every result for performance tracking
- Circuit breaker pattern for CDP connections

### JC Extension Bug Fixes

1. **listenForCorrections (content.js:1462)** — `field.name` referenced but `field` not in scope. Fixed to `el.name || el.id || 'custom'`.

2. **skipFieldForType (content.js:1429)** — `street_address` check `!/\d/.test(value)` skipped valid addresses without digits (e.g., "Grabiszyńska"). Removed.

3. **Combobox routing (form-detector.js:382)** — Added toggle button check: `isOracleCombobox(el) && (el.type !== 'text' || hasToggle)`. Text inputs with toggle button are real comboboxes, without are autocomplete.

4. **Typeahead combobox (form-detector.js:640)** — Added fallback for comboboxes that don't open via toggle button (e.g., postalCode). Types prefix → waits 1.5s → selects from dropdown.

### Content script isolated world limitation
- `page.evaluate()` dispatches events in page world, NOT content script world
- Clicking F buttons via `page.evaluate()` doesn't trigger onclick handlers
- **Workaround**: Use Playwright's `page.click()` directly on the element
- **Impact**: Test scripts that click F buttons via `page.evaluate()` won't work
