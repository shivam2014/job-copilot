Chrome loads page

entry point

Chrome reads manifest.json and injects four JS files into the page: token-tracker.js, llm-client.js, form-detector.js, content.js. They run in the page's DOM but in an isolated JavaScript world.

"content_scripts": [{
  "js": ["lib/token-tracker.js",
         "lib/llm-client.js",
         "content/form-detector.js",
         "content/content.js"],
  "run_at": "document_idle"
}]

User uploads resume PDF

options.js · handlePDF()

The settings page has a file upload area. When you drop or select a PDF, handlePDF() reads it as raw bytes and passes it to pdf.js for text extraction.

async function handlePDF(file) {
  const arrayBuffer = await file.arrayBuffer();
  const text = await extractTextFromPDF(arrayBuffer);
  await runExtraction(text, file.name);
}
